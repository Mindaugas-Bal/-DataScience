Основная цель витрины — собрать агрегированные характеристики поведения пользователей на основе их заказов.
По условию заказчика, перед формированием витрины нужно отфильтровать данные:
Витрина данных должна включать только заказы, которые были доставлены или отменены (статусы Доставлено и Отменено ).
Витрина должна быть ограничена тремя регионами с наибольшим количеством заказов.
Каждая строка в витрине должна соответствовать уникальному клиенту в конкретном регионе.
Включите в витрину product_user_features следующую информацию о клиентах маркетплейса:
Базовая информация о клиенте и времени его активности:
user_id — уникальный идентификатор клиента.
region — регион, из которого был сделан заказ. Если один и тот же клиент делал заказы из разных регионов, каждый из которых входит в топ-3 по активности, то пользователь может появляться в витрине несколько раз.
first_order_ts — дата и время первого заказа.
last_order_ts — дата и время последнего заказа.
lifetime — жизненный цикл клиента, то есть сколько дней прошло между первым и последним заказом.
Информация о заказах клиента:
total_orders — общее количество заказов.
avg_order_rating — средняя оценка, которую пользователь выставляет своим заказам.
num_orders_with_rating — количество заказов, для которых получена оценка с рейтингом.
num_canceled_orders — количество отменённых заказов.
canceled_orders_ratio — доля отменённых заказов.
Информация о платежах:
total_order_costs — суммарная стоимость всех доставленных пользователю заказов.
avg_order_cost — средняя стоимость заказа.
num_installment_orders — количество заказов, оплаченных в рассрочку.
num_orders_with_promo — количество заказов, купленных с использованием промокодов для оплаты.
Вспомогательные бинарные признаки:
used_money_transfer — использовал ли клиент денежный перевод хотя бы один раз в качестве первого типа оплаты ( 1 — использовал, 0 — не использовал).
used_installments — использовал ли клиент рассрочку хотя бы один раз ( 1 — использовал, 0 — не использовал).
used_cancel — отменял ли клиент хотя бы один заказ ( 1 — отменял, 0 — не отменял).
